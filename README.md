## 🌊 FloodSense — Intelligent IoT-Based Flood Detection & Early Warning System

FloodSense is an intelligent flood monitoring and early-warning system that combines IoT sensing, cloud technologies, machine learning and mobile application development.

### 🔹 Key Features

- Real-time water-level and rainfall monitoring
- ESP32-based environmental data collection
- Firebase Realtime Database integration
- Machine-learning-based flood risk classification
- LOW, MEDIUM & HIGH risk identification
- Android application for real-time monitoring
- Automatic warning notifications
- Local siren activation during HIGH-RISK conditions
- Fallback risk classification for improved system reliability

### 🔧 Technologies

`ESP32` `Firebase` `Python` `FastAPI` `Scikit-learn` `Kotlin` `Jetpack Compose`
